    Comment utiliser cet outil

    1️⃣
    Sélectionnez le jeu

    Choisissez le jeu Kingdom Hearts dans lequel vous avez la compétence. Laissez "Tous les jeux" si vous n'êtes pas sûr.

    2️⃣
    Tapez le nom

    Entrez le nom de la compétence (en français ou en anglais). Les suggestions vous aideront à trouver la bonne orthographe.

    3️⃣
    Révélez !

    Cliquez sur Révéler ou appuyez sur Entrée. La compétence apparaît dans votre liste, organisée par jeu.

    💾
    Sauvegarde auto

    Vos compétences débloquées sont sauvegardées dans le cache. Elles persistent entre les sessions.

    🎬
    Lire les GIFs

    Survolez un GIF pour le lire. Cliquez dessus pour verrouiller la lecture (et recliquez pour le remettre en pause).
